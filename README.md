| 구분 | 수량 | 주요 수록 내용 |
| :--- | :---: | :--- |
| **1. 🇰🇷 한국 위인·역사 명언 (`한국명언`)** | **500선** | • **국왕**: 세종대왕, 정조대왕, 태종, 성종, 영조, 태조 왕건, 고국천왕, 무열왕 등<br>• **명장/충신**: 충무공 이순신, 을지문덕, 양만춘, 강감찬, 최영, 계백, 김유신, 권율, 곽재우, 사명대사, 김종서, 안중근, 유관순, 김구, 안창호 등<br>• **대학자/선현**: 다산 정약용, 퇴계 이황, 율곡 이이, 원효대사, 지눌, 서산대사, 남명 조식, 허준, 연암 박지원, 추사 김정희, 포은 정몽주, 삼봉 정도전 및 한국 전통 속담·격언 |
| **2. 🇺🇸 세계 영어 명언 (`영어명언`)** | **500선** | • 영문 원문(`original`) + 자연스러운 한국어 번역(`korean`)<br>• 철학자, 문학가, 과학자, 현대 리더들의 명언 및 실제 저서·연설문 출전 표기 |
| **3. 🀄 사자성어 & 한자 고전 (`사자성어` / `한자명언`)** | **500선** | • 사자성어(442선) + 한자 고전 명문장(58선)<br>• 한자 원문 + 한글 독음 + 속뜻 풀이 + 글자별 한자 훈음(訓音) 및 활용 예문<br>• 《논어》, 《맹자》, 《사기》, 《손자병법》, 《채근담》, 《명심보감》 등 고전 원전 표기 |

## 🛠️ 주요 기능 (Key Features)

1. **🔍 1,500선 실시간 통합 검색 및 카테고리 필터 웹앱 (`index.html`)**
   - 키워드(원문, 번역, 인물, 출전, 뜻풀이) 실시간 검색 및 카테고리별 필터링을 제공합니다.
   - 선택한 명언이나 사자성어를 스마트폰 텔레그램 화면 스타일로 미리 보기 및 즉시 발송 테스트할 수 있습니다.

2. **📬 텔레그램 아침·저녁 자동 발송 (`send_quote.js` / `Code.gs`)**
   - 시간대(아침 `🌅` / 저녁 `🌙`)와 카테고리(영어 명언 / 한국 위인 명언 / 사자성어)에 맞춰 가독성 높은 HTML 카드 포맷으로 텔레그램 푸시 알림을 발송합니다.
   - Node.js CLI(`send_quote.js`), GitHub Actions 스케줄러, 또는 Google Apps Script(`Code.gs`) 서버리스 타이머 방식을 모두 지원합니다.

## 🚀 실행 및 데이터 빌드 방법

```bash
# 1. 한국 위인 명언 보강 및 웹/CSV 리빌드 시
node enrich_korean_greats.js
node build_web.js

# 2. 터미널에서 텔레그램으로 랜덤 명언 1건 즉시 발송 시
# (환경변수 TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID 설정 필요)
node send_quote.js
```
