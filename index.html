📖 3분 완성! 구글 시트 서버리스 연동법

  1. 구글 스프레드시트 새 문서를 열고 [파일 → 가져오기 → 업로드]에서 폴더 안의 quotes_1000.csv 파일을 업로드합니다.
  2. 상단 메뉴 [확장 프로그램 → Apps Script]를 클릭합니다.
  3. 위 [📋 내 토큰이 적용된 Code.gs 복사] 버튼을 눌러 복사한 코드를 붙여넣고 저장(Ctrl+S)합니다.
  4. 상단 함수 선택창에서 setupMorningEveningTriggers를 선택하고 [실행]을 누르면 매일 아침·저녁 자동 푸시 알림 설정 끝!
