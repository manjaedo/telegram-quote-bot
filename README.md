# 📬 서버리스 1,000 명언 & 사자성어 텔레그램 푸시 알림 봇 (Google Sheets + Apps Script)

별도의 유료 서버나 PC를 켜둘 필요 없이, **구글 스프레드시트(Google Sheets)**와 **Google Apps Script**의 무료 타이머를 이용해 매일 **아침(오전 8시)**과 **저녁(오후 9시)** 핸드폰 텔레그램으로 명언·사자성어 푸시 알림을 보내주는 프로젝트입니다.

---

## 📂 생성된 파일 구성

- [`quotes_1000.csv`](./quotes_1000.csv) : 구글 스프레드시트에 바로 업로드할 수 있는 **1,000개 명언·사자성어 데이터셋** (엑셀/구글 시트 한글·한자 깨짐 방지 UTF-8 BOM 적용)
  - **영어 명언 (500개)**: 🇺🇸 영어 원문 + 🇰🇷 한국어 번역 + ✍️ 말한 사람(한/영 병기) + 📖 출전
  - **사자성어 & 한자 고전명언 (500개)**: 🀄 한자 표기(독음 병기) + 💡 한국어 뜻풀이 + 📝 한자 훈음·예문·유래 + 📚 출전/인물
- [`Code.gs`](./Code.gs) : 구글 스프레드시트의 **Apps Script**에 붙여넣을 서버리스 자동 발송 코드
- [`QuotesData.gs`](./QuotesData.gs) : *(선택사항)* CSV 파일 업로드 대신 Apps Script 코드만으로 시트에 1,000개를 자동 입력하고 싶을 때 함께 붙여넣는 데이터 파일
- [`index.html`](./index.html) : 브라우저에서 더블클릭해 바로 열 수 있는 **1,000개 명언 검색기 & 내 텔레그램 즉시 테스트/코드 자동 생성 대시보드**
- [`quotes_1000.json`](./quotes_1000.json) : 1,000개 명언 원본 JSON 파일

## 📱 텔레그램 푸시 알림 예시

### 1) 영어 명언 발송 시
```text
🌅 [오늘 아침의 오늘의 명언] #1
━━━━━━━━━━━━━━━━━━
🇺🇸 "Believe in yourself. You are braver than you think."

🇰🇷 "너 자신을 믿어라. 너는 생각보다 용감하다."

✍️ — A. A. 밀른 (A. A. Milne)
📖 출전: Pooh's Grand Adventure: The Search for Christopher Robin
```

### 2) 한자 사자성어 / 한자 명언 발송 시
```text
🌙 [오늘 저녁의 사자성어] #202
━━━━━━━━━━━━━━━━━━
🀄 四面楚歌 (사면초가)

💡 한국어 풀이
사방이 적에게 둘러싸여 누구의 도움도 받을 수 없는 매우 고립된 상태를 이르는 말

📝 한자·상세 해설
훈음: 넉 사/낯 면/나라 초/노래 가 | 예문: 거짓말이 하나씩 밝혀지면서 그는 사면초가에 빠져 아무도 편을 들어 주지 않았다.

📚 출전/인물: 사기
```

## 🚀 3분 완성! 설치 및 자동 알림 설정 가이드

### Step 1. 텔레그램 봇 만들기 (`Bot Token` 발급)
1. 핸드폰 텔레그램 상단 검색창에 **`@BotFather`** 를 검색해 대화를 시작합니다.
2. 채팅창에 `/newbot` 을 입력해 전송합니다.
3. 봇의 이름(예: `오늘의 명언 봇`)을 입력하고, 이어서 끝에 `bot`으로 끝나는 아이디(예: `my_daily_quote_1000_bot`)를 입력합니다.
4. 발급된 **HTTP API 토큰**(`1234567890:AAHdqTcv...` 형태)을 복사해 둡니다.
5. 방금 생성된 내 봇 링크를 눌러 들어간 뒤 **[시작(Start)]** 버튼을 누르고 아무 메시지(예: `안녕`)나 한 번 보냅니다.

### Step 2. `index.html` 열어서 테스트 & 맞춤 코드 복사하기 (가장 쉬운 방법!)
1. 폴더 안의 [`index.html`](./index.html) 파일을 더블클릭해 크롬/엣지 브라우저로 엽니다.
2. 복사한 **Bot Token**을 입력하고 **[🔍 자동 조회]** 버튼을 누르면 내 **Chat ID**가 자동으로 입력됩니다.
3. **[🚀 지금 선택된 명언을 내 핸드폰 텔레그램으로 쏘기!]** 버튼을 눌러 내 폰에 푸시 알림이 잘 오는지 바로 확인합니다.
4. **[📋 내 토큰이 적용된 Google Apps Script(Code.gs) 복사]** 버튼을 누르면 내 토큰과 Chat ID가 이미 들어간 코드가 복사됩니다!

### Step 3. 구글 스프레드시트 + Apps Script 등록하기
1. [Google 스프레드시트](https://sheets.new)에서 새 시트를 엽니다.
2. 상단 메뉴 **[파일] → [가져오기] → [업로드]** 탭을 선택하고 [`quotes_1000.csv`](./quotes_1000.csv) 파일을 끌어다 놓습니다.
   - 가져오기 위치: **'현재 시트 대치'** 선택 후 **[데이터 가져오기]** 클릭!
3. 상단 메뉴 **[확장 프로그램] → [Apps Script]**를 클릭합니다.
4. 기존 `function myFunction() {}`을 모두 지우고, 복사해 둔 [`Code.gs`](./Code.gs) 내용을 붙여넣은 뒤 **저장(`Ctrl + S`)**합니다.
5. 상단 실행할 함수 목록(기본 `onOpen`으로 표시된 드롭다운)을 클릭하여 **`setupMorningEveningTriggers`** 로 바꾼 뒤 **[▷ 실행]** 버튼을 누릅니다.
   - 최초 1회 권한 검토 창이 뜨면 **[권한 검토] → 본인 구글 계정 선택 → [고급] → [(제목 없는 프로젝트)(으)로 이동(안전하지 않음)] → [허용]**을 순서대로 눌러줍니다.

이제 모든 설정이 끝났습니다! 컴퓨터와 핸드폰을 꺼두어도 구글 서버가 **매일 아침 8시, 저녁 9시**에 아직 보내지 않은 명언 중 하나를 랜덤하게 골라 텔레그램 푸시 알림으로 보내줍니다.
